## 作品について

阿仏尼が歌の道を学ぶ人に向けて、詠歌の心構えや古歌・今の歌の学び方を説いた歌論。ここの本文は国文学研究資料館所蔵の版本『和歌六部抄』の一冊で、題は「和歌口伝」となっている。

国文学研究資料館の公開画像です（画像の出典: 国文学研究資料館）。

## 本文の作り方

国文学研究資料館の公開画像を、国立国会図書館の NDL古典籍OCR-Lite でテキスト化し、原本のページごとに段落に分けました。版本の崩し字の OCR なので、誤りが多く残っています。版本の頭の書き入れ（ほかの集に入っていることを示す注）は、出典・注として分けています。

## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 段落で、`段落ID<TAB>本文` の形です。原本の行の切れ目は ⏎ で示しています（⏎ は改行の印で、本文の字ではありません）。50段落ごとにファイルを分けています（1ファイル）。 |
| `uta.tsv` | 作中歌の一覧（番号・段落ID・本文・読み・詠み手・種別・原本のコマ）。 |
| `nijl-yoru-no-tsuru.json` | 本文・底本・作品の説明・作中歌のデータをまとめた JSON（訳は入れず、`yaku/` だけに置いています）。 |

段落ID（例: `nijl-yoru-no-tsuru-0001`）は、本文を直しても変わりません。

## 誤りを見つけたら


- **Issue で知らせる**：[「本文の誤り」の Issue を作る](https://github.com/kumoi-no-fumigura/yoru-no-tsuru-nijl/issues/new?template=teisei.yml)。段落ID・いまの本文・直した本文・根拠を書いてください。
- **直接直す**：`honbun/` の該当行を直して Pull Request を送ってください。段落IDと行の順番は変えないでください。

受け取った修正は、底本と照らして確かめてから取り込みます。
